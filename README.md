# 零下三十七

一栋楼，六个人，一场不会停的冷。

玩家是 6 楼 601 的住户，楼里没人知道。玩家家里有吃不完的东西，但只能看着别人在群里互相猜。

## 这是什么

一个**观察型末日模拟器**。七个 AI 角色住在同一栋封死的居民楼里，唯一的联系是业主微信群。

- **你能看见**：每个人在几楼、体温多少、是不是站在你门口
- **你看不见**：他们心里怎么想你
- **你能做**：投送物资、私聊、收进空间、在群里说话

每句话都是当场由模型生成的，不是预设台词。

## 怎么玩

打开页面，点 **「▶ 一段」** 推进时间。每推一次，游戏里过两分钟，AI 会根据「谁冷了、谁饿了、群里在说什么」决定谁开口。

- 左上角是楼栋剖面图，条越短人越冷
- 中间是业主群
- 右侧点谁就切到谁：私聊 / 投送 / 收进空间
- 左下角是实时花费（人民币）

## 三条主线

**传播链**：你只要投过一次东西，或者被人看见过一次，「601 有东西」就会在楼里传开。有人会拿它当筹码，有人会替你说话，也有人会当场挑明。

**女主线**：赵小雅不肯开口。她的体面从 100 掉到 0，她才会来敲你的门。在那之前，她只会在群里绕圈子。

**结局**：第 7 天 00:00 自动收尾。判定看你这七天做了什么——空屋、满屋、一盏灯、分光、还是关着。

## 架构

```
index.html        入口
style.css         样式（深色，iPad 双栏，窄屏自动折叠）
js/world.js       代理地址、常量
js/cast.js        12 个人物池，每人 3 个性格切面，开局抽 6 个
js/ai.js          prompt 构造与模型调用
js/thread.js      每个角色的常驻记忆（摘要 + 最近 12 句）
js/repeat.js      防复读：说过的话记下来，撞了就重写
js/spread.js      传播链：谁知道 601 有东西
js/arc.js         女主线：赵小雅的体面
js/timeline.js    关系时间线
js/aftermath.js   挑明之后的第 5 天政治
js/ending.js      第 7 天结局
js/save.js        存档（服务端 + localStorage 双写）
js/engine.js      时钟、生理衰减、事件调度
js/ui.js          渲染
server/serve.py   本地代理：模型调用 + 人民币记账 + 静态文件
start.sh          一键起服务 + 公网隧道
```

## 为什么需要一个代理

浏览器里直接调模型 API 有两个问题：**API key 会暴露**，而且会有 CORS。

所以需要一个后端中转。`server/serve.py` 就是干这个的：

- `POST /api/llm` → 转发给模型，返回文本
- `GET /api/cost` → 按 token 记人民币账
- `GET/POST/DELETE /api/save` → 存档

页面上的 `AW` 常量指向这个代理。可以用 `?proxy=https://你的代理地址` 覆盖。

## 本地跑

```sh
python3 server/serve.py            # HTTPS，端口 8843，需要 server/cert.pem
PLAIN=1 python3 server/serve.py    # 或者走 HTTP
```

模型调用依赖 `minis-model-use` 命令行（本项目的原生运行环境），换成你自己的 API 只需要改 `server/serve.py` 里的 `call_model()`。

## 已知限制

- **时间要手动推**。后台标签页里 `requestAnimationFrame` 会被浏览器冻结，定时器也会被节流，所以自动推进不可靠
- **地址会变**。免费隧道每次重启都换域名，需要重新跑 `start.sh`
- **模型会抖**。加了防复读和说话角度约束，但偶尔还是会有人说话不像自己

## 花费

一次对话大约 ￥0.0004，玩一整天几毛钱。
